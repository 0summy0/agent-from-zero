# 2.2 Tool Calling: From a Plan to Controlled Local Execution

## 1. What this chapter tackles

A structurally valid plan is still not permission to execute. This chapter connects “the model proposes a plan” with “the program runs a tool,” ensuring that only registered, allowed tools with valid arguments can run.

The example has two local tools: `calculator` evaluates arithmetic, and `lookup_city` queries a fixed city table. Everything runs on the CPU without network access, a GPU, or a paid API.

## 2. The registry and a safe calculator

`TOOL_REGISTRY` stores each tool handler and its parameter types. `ALLOWED_TOOLS` is the default allowlist; a caller may pass a smaller set, but this never enables tools outside the registry.

The calculator does not use `eval()`. It parses the expression into an AST and accepts only numbers, unary signs, and `+`, `-`, `*`, `/`, `//`, `%`. Function calls, name references, and other syntax are rejected. `lookup_city` reads only the three cities built into this chapter and never contacts an external service.

## 3. Execute a structured plan

From the repository root, run:

```bash
uv run python chapters/stage2-agent-core/tool_calling.py
```

`run_minimal_path()` parses the plan `(6 + 2) * 7`, invokes the calculator, and returns `chapter`, `tool`, `arguments`, and `result`. The result is the integer `56`, and repeated runs are identical.

## 4. Four checks before execution

`execute_plan()` first calls `parse_plan()` to check the three plan fields and the confidence range. It then enters `call_tool()`:

1. The tool must exist in the registry.
2. The tool must be in the allowlist for this call.
3. Arguments must be complete, contain no extra fields, and have the correct types.
4. The handler must also accept the expression or city itself.

A failed check raises `ValueError`. The code neither ignores the error silently nor falls back to a different tool.

## 5. Restrict tool permissions yourself

Pass this code to `uv run python -`:

```python
import runpy

chapter = runpy.run_path("chapters/stage2-agent-core/tool_calling.py")
plan = {"action": "calculator", "arguments": {"expression": "2 + 3 * 4"}, "confidence": 0.9}
print(chapter["parse_plan"](plan))
print(chapter["execute_plan"](plan))
try:
    chapter["execute_plan"](plan, allowed_tools={"lookup_city"})
except ValueError as exc:
    print(exc)
```

The first two outputs show the normalized plan and the result `14`. The last output is the allowlist rejection. The smoke tests also check unknown tools, invalid arguments, and deterministic execution.
