# 1.2 Sampling: How Temperature and Top-p Change the Next Token

## 1. What this chapter tackles

After a model produces a probability distribution for the next token, it still needs to choose one. This chapter uses a tiny pure-Python bigram model to show how temperature sharpens or flattens a distribution and how top-p removes low-probability candidates.

No GPU, model weights, or API key is required. The toy data is intentional: the goal is to understand sampling, not model quality.

## 2. From probabilities to a choice

`next_token_distribution()` counts how often each word follows `the` and uses add-one smoothing to avoid zero probabilities. `apply_temperature()` divides log-probabilities by the temperature and normalizes again.

- Temperature below 1 makes high-probability tokens stand out and usually stabilizes output.
- Temperature above 1 flattens the distribution and increases variety.
- Temperature must be greater than zero; this chapter rejects zero and negative values.

## 3. Run the sampling experiment

From the repository root, run:

```bash
uv sync --frozen
uv run python chapters/stage1-how-lm-works/sampling.py
```

The output contains three distributions: the original distribution, the distribution at temperature 0.5, and the candidate distribution after top-p 0.8. `nucleus_original_mass` is the probability mass covered before renormalization, while `sampled_token` is chosen with a fixed seed.

## 4. Why top-p is called nucleus sampling

Top-p does not keep a fixed number of tokens. It sorts candidates by probability and accumulates them until the threshold is reached. A confident model keeps few candidates; an uncertain model keeps more.

The threshold 0.8 means “cover at least 0.8 of the probability mass.” The retained set may therefore have an original mass slightly above 0.8 rather than exactly 0.8.

## 5. Inspect the result

Pass this code to `uv run python -`:

```python
import runpy

chapter = runpy.run_path("chapters/stage1-how-lm-works/sampling.py")
result = chapter["run_minimal_path"]()
print(result["base_distribution"])
print(result["tempered_distribution"])
print(result["nucleus_distribution"])
print(result["sampled_token"])
```

The smoke tests check that all distributions are normalized, lower temperature sharpens the distribution, top-p retains enough mass, and a fixed seed produces reproducible results.
