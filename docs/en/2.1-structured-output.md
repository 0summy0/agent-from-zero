# 2.1 Structured Output: Validating Tool Plans with JSON Schema

## 1. What this chapter tackles

A model can generate text that looks like a tool call, but “parseable” does not mean “safe to execute.” This chapter restricts a tool plan to one JSON object: `action` selects a tool, `arguments` supplies its parameters, and `confidence` records confidence.

The goal is to validate structure and types before considering execution. The examples run entirely locally and require no GPU, network, or API key.

## 2. Make the contract explicit with a schema

`TOOL_PLAN_SCHEMA` requires all three fields: `action` is a non-empty string, `arguments` is an object, and `confidence` is a number from 0 to 1. `additionalProperties: false` rejects extra fields so typos cannot slip into a plan unnoticed.

`validate_plan(plan)` returns `(valid, errors)`. `valid` is a boolean, and `errors` is a list of strings that can be displayed or logged. A valid plan has an empty error list.

## 3. Compare a valid and an invalid plan

From the repository root, run:

```bash
uv run python chapters/stage2-agent-core/structured_output.py
```

`run_minimal_path()` compares two plans. The valid plan contains every field, so its `valid` value is `true`. The invalid plan lacks `confidence`, so its `valid` value is `false` and the error identifies the missing field. Every value in the result is JSON serializable.

## 4. Repair the transport layer, not the content

Models sometimes wrap JSON in a Markdown code fence. `repair_json(text)` can extract the content of one `json` fence or parse ordinary JSON text directly. It rejects malformed JSON, JSON that is not an object, and multiple JSON fences.

This function repairs only the outer wrapper. It does not invent missing fields or coerce incorrect types. Call `validate_plan()` after extraction: JSON parsing and schema validation are separate checks.

## 5. Inspect the result

Pass this code to `uv run python -`:

```python
import runpy

chapter = runpy.run_path("chapters/stage2-agent-core/structured_output.py")
plan = {"action": "calculator", "arguments": {"expression": "2 + 2"}, "confidence": 0.9}
print(chapter["validate_plan"](plan))
fenced = (
    '```json\n{"action": "lookup_city", "arguments": {"city": "Beijing"}, "confidence": 0.8}\n```'
)
print(chapter["repair_json"](fenced))
print(chapter["run_minimal_path"]())
```

The smoke tests cover valid plans, missing fields, incorrect types, fence extraction, and malformed JSON. Try changing `confidence` to a string and inspect the resulting error.
