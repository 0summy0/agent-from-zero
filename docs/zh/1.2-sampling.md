# 1.2 采样：温度与 top-p 怎样改变下一个 token

## 1. 这一章要解决什么

模型给出下一个 token 的概率分布后，还要决定“选哪一个”。本章用一个纯 Python 的小型 bigram 模型，亲手观察温度如何让分布变尖或变平，以及 top-p 如何裁掉低概率候选。

不需要 GPU、模型权重或 API key。我们故意使用玩具数据，因为这里的重点是采样机制，不是模型效果。

## 2. 从概率分布到一次选择

`next_token_distribution()` 先统计语料中每个词出现在 `the` 后面的次数，并用加一平滑避免零概率。`apply_temperature()` 对概率取对数后除以温度，再重新归一化。

- 温度小于 1：高概率 token 更突出，输出更稳定。
- 温度大于 1：概率更平均，输出更多样，也更容易偏离常见模式。
- 温度必须大于 0；本章不接受 0 或负数。

## 3. 跑通采样实验

在仓库根目录执行：

```bash
uv sync --frozen
uv run python chapters/stage1-how-lm-works/sampling.py
```

输出里可以看到三份分布：原始分布、温度为 0.5 的分布、top-p 为 0.8 的候选分布。`nucleus_original_mass` 是裁剪前候选集合占原始分布的概率质量，`sampled_token` 是用固定 seed 选出的结果。

## 4. top-p 为什么叫“核采样”

top-p 不固定保留前 k 个 token，而是按概率从高到低累加，直到累计概率达到阈值。这样在模型很确定时只保留很少候选，在模型犹豫时保留更多候选。

需要注意：阈值 0.8 表示“至少覆盖 0.8 的概率质量”，所以最终保留集合的原始质量可能略高于 0.8，而不是恰好等于 0.8。

## 5. 亲手检查结果

把下面代码交给 `uv run python -` 执行：

```python
import runpy

chapter = runpy.run_path("chapters/stage1-how-lm-works/sampling.py")
result = chapter["run_minimal_path"]()
print(result["base_distribution"])
print(result["tempered_distribution"])
print(result["nucleus_distribution"])
print(result["sampled_token"])
```

冒烟测试会检查三份分布都归一化、低温确实让分布更尖、top-p 覆盖足够质量，以及固定 seed 的结果可复现。
